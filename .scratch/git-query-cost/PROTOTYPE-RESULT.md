## 有效性检查

最终原型通过 18 个定向检查和 5 个既有用例。源码、HEAD、primary target 索引、分支、symlink、包身份变化分别注入授权前与发动作前。授权前证明没有调用 checkpoint 转换；发动作前证明原转换已完成；均未发出宿主动作。还检查了最终校验中途由外部进程切分支、unsafe checkpoint、公开声明伪造、入口 binding 与 B binding 不一致、保存 B 结果后的恢复，以及讨论 reservation 被真实账本取消。

五个既有用例覆盖崩溃恢复、旧 revision、暂停/取消、兼容注册保留原包、真实 ledger lost-bind 恢复。独立只读复核确认对应断言支持这些限定结论；没有把有限用例扩写成所有并发和权限情形已验证。

初版曾做到 95 次，但同一关口中途外部切分支会复用旧绑定并误发宿主动作，因此淘汰。最终版本将重复绑定检查集中到最晚检查点，并在该点前丢弃动态读取；这里的收益来自调整职责和共享具体事实，不能靠直接跨检查缓存来实现。
