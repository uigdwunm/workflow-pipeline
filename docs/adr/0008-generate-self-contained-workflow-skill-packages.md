# ADR-0008: 从共享源码生成自包含工作流 Skill 包

Status: Proposed

## Context

五个 Workflow Stage 的用户入口可以独立使用，但内部文档、Python 导入和阶段定位依赖兄弟安装目录。用户需要只安装一个阶段；同时不能复制维护多份规则、分裂 ledger 或扩大 Stage 3 职责。

## Decision

源码入口使用不可安装的模板名称，共享协议有一个源码所有者；仓库唯一可发现的五个 Skill 入口是确定性构建生成的安装包。每包带完成自身职责的内部资源闭包，不带其他阶段入口或 Matt 内容。

本阶段内部资源只在本包中解析。实际进入其他阶段时使用当前有效 Skill 注册结果，校验真实包身份和完全相等的协议兼容键。文件系统扫描仅为诊断。一个运行固定使用已核验的不可变包身份，升级仅影响新运行；不引入依赖求解器或自动安装器。

代码副本继续共享原 canonical project/Git common directory 推导的 ledger、checkpoint 和锁。ADR-0001、0005、0006、0007 的状态、职责、角色与权限保持。Stage 3 保留候选和 worktree，Stage 4 最终发布和清理。

## Consequences

发布包会重复携带共享运行代码，开发只维护单一源码；构建检查负责防漂移。旧安装目录推导不再是交接机制。初版只接受协议键完全相等的组合，旧 runner 记录由原运行时恢复，避免猜测身份迁移。详细边界、失败语义、测试和迁移切片由对应独立安装 Spec 拥有。

本 ADR 随方案提交供评审，尚未实施，不改变现有运行协议。
