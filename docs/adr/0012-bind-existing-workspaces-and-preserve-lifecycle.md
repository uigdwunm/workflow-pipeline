# ADR-0012: 复用独立工作区，并保留来源对应的生命周期

Status: Accepted
Amends: ADR-0005 的工作区创建约定，以及既有 Flow Worktree 的统一删除约定；阶段入口授权不变。

流程需要可核验的隔离、需求版本和唯一写者。强制每个独立入口调用脚本新建工作区把目标绑定到具体操作；强制归档时删除又使复用空间无法安全完成。

Stage 2、独立 Stage 3/4 先核验原绑定，再检查当前及宿主关联的可用独立工作区。没有合适空间时优先宿主管理创建，传入确切目标提交；仅在宿主规则允许的后备条件下使用脚本。Controller 保存实际选择及宿主证据，Git 接纳入口只核验注册、仓库身份、分支、基线和任务范围。干净目录不证明空闲，未知创建结果先核对原操作。阶段继承和重试沿用原绑定。

Worktree Binding 同时携带来源、管理方式、完成处置和证据引用。复用空间及宿主管理空间保留工作区和分支；脚本本次创建的临时资源依照其创建回执按原非强制规则删除。完成定义为目标交付及绑定处置均已核验。恢复保留原处置，不重复合并，也不能把保留改成删除。宿主归档是后续独立动作，不作为本次完成条件。状态复用原 Controller checkpoint，不新增工作区登记库。

Stage 2 当前对话需求可在合适的独立空间冻结。来源不在目标历史时，复用有界文档交付，仅交付已授权快照；源提交与目标交付提交分别保留。停写、干净状态下按受控范围整合目标，核验后再封存方案基线。Stage 1 及讨论源的归属和权限不变。

方案执行者优先原身份恢复。原身份不可续用且宿主证明所有旧写者停止、未决调用结清后，Controller 固定需求、授权、路径和成果快照，在原 checkpoint 记录唯一替换意图。新执行者只读核验后才激活写权。范围不变的技术恢复不新增用户审批；业务或权限变化、取消暂停、证据缺失仍遵守原门槛。既有发布事实不因执行者丢失而重做。

第 1 阶段专用对话默认行为和普通子话题首轮仅交接的轮次门槛保持原样。本决策不迁移正在运行的旧包和记录，不依赖 ADR-0011 尚未实现的接管能力。
