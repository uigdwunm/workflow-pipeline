# 需求：减少 Skill 执行中的无效返工

## 目标
评估并落实三项最小规则补强，减少同一根因导致的反复返工，同时不增加普遍流程负担。

## 范围
1. 方案就绪检查核对本次变更涉及的既有接口、状态、调用时序、规格与真实调用链；发现矛盾先解决。
2. TDD 纵向切片先用代表性行为验证本次改变的关键真实内部边界，再扩展同类实现；不得用替身绕过该边界。
3. 同一失败机制修复后再现、产生同类回归或方案反复推翻时，先诊断前次修复为何无效，补最小有效验证并检查受影响同类路径，再继续修复。

## 约束与非目标
不新增流程阶段、独立审查文档、固定轮次门禁、自动换 Agent 或普遍端到端测试要求；不修改业务代码。

## 验收
现有 Skill 文档明确上述适用条件、动作和边界；相关文档检查通过。
