# 1. 调用 grill-with-docs

使用 [SKILL.md 的“输入与前置条件”](../SKILL.md#输入与前置条件)中已经明确的拷问依据、目标和目标项目，用户已确认的讨论要点、所选分支的补充要求，以及用户仍有效的执行要求，作为本次调用的输入。

利用当前对话中已有的讨论上下文和用户指定资料，从前置检查已核实的实际入口读取 `grill-with-docs` 的完整 `SKILL.md`，按其原流程执行。入口无法读取或需要重新定位时，按共用的登记查询和意外中断规则处理。

将 [SKILL.md 的“已有讨论文档”规则](../SKILL.md#已有讨论文档)，以及进入本阶段时已经确定的文档信息，作为本次调用的补充要求一并传入。已有文档时提供实际路径或链接，没有时明确说明。

一并传入 [SKILL.md 的“拷问末尾的测试范围”规则](../SKILL.md#拷问末尾的测试范围)，在 `grill-with-docs` 的最终理解确认中完成适用的测试边界确认，并将结论及确认依据纳入执行结果。

执行中需要用户回答或确认时，在当前对话中完成后继续。

执行完成后，汇总本次讨论的最终结论，以及实际维护或生成的文档及其位置。没有文档产物时如实说明。

# 2. 结束或中断执行

- **正常完成**：`grill-with-docs` 原流程、所需用户确认及适用的文档维护已完成，返回调用方登记“执行拷问”完成，再按照 [完整流程中“任务完成”的处理要求](clarification-flow.md#任务完成)核对讨论结果和实际文档。
- **意外中断**：执行中发生导致任务无法继续的意外时，暂停执行，按照 [完整流程中“意外中断”的处理要求](clarification-flow.md#意外中断)处理。
